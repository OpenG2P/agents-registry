# Agents Registry

An OpenG2P reference registry of the agents who serve farmers (extension agents,
development agents, animal health workers) and their trainings, built on the
OpenG2P [registry platform](https://github.com/OpenG2P/registry-platform).

Documentation: [Agents Registry](https://docs.openg2p.org/products/open-agri-stack/registries/agents-registry)
on docs.openg2p.org — what it holds, [customisation](https://docs.openg2p.org/products/open-agri-stack/registries/agents-registry/customisation),
[deployment](https://docs.openg2p.org/products/open-agri-stack/registries/agents-registry/deployment) and
[versions](https://docs.openg2p.org/products/open-agri-stack/registries/agents-registry/versions).
